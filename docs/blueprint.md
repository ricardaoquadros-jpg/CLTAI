# **App Name**: Financial Glimpse

## Core Features:

- Income Input: Allows users to input their income details (amount, frequency - daily, business days, hourly).
- Account and Investment Input: Allows users to input their bank balance and investment amounts.
- Real-time Earnings Update: Calculates and displays real-time earnings based on user-defined income frequency.
- Dashboard: Presents a dashboard view with current balance, investment, and real-time earnings.
- Expense Tracker: Allows users to input and track their expenses throughout the month.
- Login Authentication: Secure login using email and password with session management.

## Style Guidelines:

- Primary color: A calming blue (#4A8FE7) to inspire trust and stability, avoiding direct associations with money.
- Background color: Light gray (#F0F4F7) to create a clean and modern look.
- Accent color: Soft green (#86E0A4) for positive indications and calls to action, creating contrast without the association with money.
- Body and headline font: 'PT Sans' (sans-serif) for a modern, readable, and accessible design.
- Use clear, minimalist icons to represent different financial aspects.
- Dashboard should feature a clean, tabbed design for easy navigation and data input.
- Use subtle transitions and animations for data updates and user interactions to enhance the user experience.
